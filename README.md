# claude-skills

Личные скиллы для [Claude Code](https://claude.com/claude-code), общие для всех проектов.

## Скиллы

| Скилл | Что делает |
|---|---|
| [`/conveyor`](skills/conveyor/SKILL.md) | Конвейер для большой задачи: координатор исследует задачу, нарезает ее на таски с брифами, раздает исполнителям-субагентам, гоняет ревьюера и сводит результат. Очередь тасок хранится в файлах вне репозитория проекта |

## Установка (Windows)

```powershell
git clone https://github.com/paatrofimov/claude-skills.git E:\claude-skills
powershell -ExecutionPolicy Bypass -File E:\claude-skills\install.ps1
```

Скрипт:
- подключает каждую папку из `skills/` в `~/.claude/skills/` через junction, так что правки в репо видны сразу;
- создает рабочую папку для очередей `/conveyor` (по умолчанию `claude-skills-work` рядом с репо, свою можно передать
  через `-WorkDir`) и записывает ее в переменную пользователя `CONVEYOR_WORK_DIR`.

После установки перезапустите Claude Code: переменная окружения подхватывается только новым процессом.
Без переменной `/conveyor` кладет очереди в `~/.claude/conveyor`.

## Как пользоваться `/conveyor`

```
/conveyor <описание задачи>
/conveyor <путь к папке очереди>   # продолжить начатое
```

Скилл сам спросит недостающее, покажет план тасок и не начнет правки без одобрения.
Ничего не коммитит и не пушит без отдельной просьбы.
