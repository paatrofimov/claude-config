# claude-config

## Скиллы

| Скилл | Что делает |
|---|---|
| [`/fast-security-review`](skills/fast-security-review/SKILL.md) | Быстрое read-only security-ревью git-диффа относительно базовой ветки перед MR: только подтвержденные регрессии безопасности |
| [`/mr-review`](skills/mr-review/SKILL.md) | Ревью чужого MR: сначала подробное объяснение проблемы для человека без контекста (кто наблюдает, сценарии, критичность, масштаб, альтернативы, тесты) и шаги ручного воспроизведения, потом разбор решения |
| [`/mr-self-review`](skills/mr-self-review/SKILL.md) | Доводит задачу в ветке до MR: отдельный worktree, коммиты итераций self-review, короткое описание MR с ручной проверкой |
