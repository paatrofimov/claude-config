# claude-config

## Скиллы

| Скилл | Что делает |
|---|---|
| [`/conveyor`](skills/conveyor/SKILL.md) | Конвейер для большой задачи: координатор исследует задачу, нарезает ее на таски с брифами, раздает исполнителям-субагентам, гоняет ревьюера и сводит результат. Очередь тасок хранится в файлах вне репозитория проекта |
| [`/mr-review`](skills/mr-review/SKILL.md) | Ревью чужого MR: сначала подробное объяснение проблемы для человека без контекста (кто наблюдает, сценарии, критичность, масштаб, альтернативы, тесты) и шаги ручного воспроизведения, потом разбор решения |
| [`/mr-self-review`](skills/mr-self-review/SKILL.md) | Доводит задачу в ветке до MR: отдельный worktree, коммиты итераций self-review, описание MR «что поменялось и для кого», документ для ревьюера |
