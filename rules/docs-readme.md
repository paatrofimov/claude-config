# README и доки для людей

Документ для человека читается за 5–7 минут: ориентир – одна страница, около 40–60 строк.

- Только то, что нужно читателю, чтобы действовать: что это, что запускать, в каком порядке, что получится.
  Детали реализации и пересказ кода – в doc-комментариях и коде, не в README.
- Термин объясняется до первого употребления: читатель не должен догадываться, о каком канале или ключе речь.
- Блоков кода, повторяющих код, не писать: вместо примера – ссылка на место в репо, где это используется.
- Текст читается как текст: вещи называются словами, имя из кода – только если без него не найти, и один раз.
- Списки, которые дублируют код (метрики с тегами, ключи настроек), в README не писать: они видны в коде
  и в инструментах, а в README только устаревают.
- Новое добавлять, вытесняя менее важное, а не дописывая разделы. Разросся – сжать и переорганизовать.
- Таблицы и короткие списки вместо абзацев; каждая фраза дает новое, очевидное не писать.
- Перед сдачей перечитать как читатель: у каждого предложения есть подлежащее и глагол, слова однозначны,
  важный шаг не потерялся при сжатии, примеры совпадают с текстом, факты верны по коду.
